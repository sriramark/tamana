ARIMA(p,d,q) Model Equation
$$\phi(B)(1-B)^d Y_t = \theta(B)\varepsilon_t$$
$\phi(B) = 1 - \phi_1 B - \phi_2 B^2 - \cdots - \phi_p B^p$  (AR polynomial)
$\theta(B) = 1 + \theta_1 B + \theta_2 B^2 + \cdots + \theta_q B^q$  (MA polynomial)
$\varepsilon_t \sim WN(0, \sigma^2)$  (White Noise)

Fitted ARIMA Equation
$$\hat{Y}_t = \sum_{i=1}^{p}\phi_i Y_{t-i} + \sum_{j=1}^{q}\theta_j \varepsilon_{t-j} + \varepsilon_t$$
The model uses the last {{ p }} demand observations (AR part) and the last {{ q }} forecast errors (MA part) to predict the next demand value. $\sigma^2 = {{ model_info.sigma2 }}$ is the estimated error variance.
Residual Diagnostics
What are Residuals?
$$\hat{\varepsilon}_t = Y_t - \hat{Y}_t$$
Residuals $\hat{\varepsilon}_t$ are the differences between actual and fitted values. A well-fitted ARIMA model produces residuals that behave like White Noise: $\varepsilon_t \sim \mathcal{N}(0, \sigma^2)$, i.e., zero mean, constant variance, and no autocorrelation.

Diagnostics to check:
1. Residuals vs Time - should look random (no pattern)
2. Histogram - should be bell-shaped (normal distribution)
3. Q-Q Plot - points should lie on the 45° line (normality)
